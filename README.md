# 🍺🍺 Tom Waits Løpet Tracker 🍺🍺

Dette er en enkel web app for å holde oversikt over hvilke barer man har vært innom på [Tom Waits-løpet](https://tomwaitsoslo.no/). Ingen informasjon lagres utenom din enhet. Den er gratis å bruke.

Del gjerne med andre, ved å bruke QR koden under.
